# App icon sources

`icon.svg` (default), `icon-dark.svg` (Dark home screen) and `icon-tinted.svg` (Tinted home screen:
a grayscale glyph on transparent, iOS colors it). Rendered at 1024×1024 into
`SecondBrain/Assets.xcassets/AppIcon.appiconset/` — open each in a browser at 1024 px and save, or
use any SVG renderer. No purple, on purpose.
